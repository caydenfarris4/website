# Design reference

`DESIGN.md` here is an **external reference, not this site's design
system**. It is the "claude" (Anthropic) design analysis from
[voltagent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md),
copied verbatim — chosen because its warm-canvas editorial language
(cream surfaces, serif display headlines, humanist warmth) is the
closest published match to this site's own identity.

Use it as inspiration when improving pages: spacing systems, type
scale discipline, surface/hairline color roles, component polish.

Do NOT copy its palette or brand voice directly — this site's actual
design language (Cormorant Garamond/Lora; cream `#faf6ef`, gold
`#b8840a`, espresso `#1c1208`; blueprint-grid motif) is defined in
`CLAUDE.md` and in each page's inline `:root` tokens, and always wins
over this reference.

It sits in `design-reference/` (not the repo root) on purpose: a
root-level `DESIGN.md` would be auto-read by AI agents as the
project's own design system.
